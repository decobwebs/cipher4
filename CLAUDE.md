# Cipher4 website: standing rules for Claude Code

The full plan is in `design-handoff/BUILD-PLAN.md`. Read it before any work.

## Always
- Work on the `redesign` branch. Never push to `main`.
- Stop at the end of each phase and wait for approval.
- Copy comes only from `design-handoff/content/cipher4-website-content-v1.md`.
- Visual reference comes from `design-handoff/design/renders/`. Exact values come from `design-handoff/design/boards/`.
- Use only the design tokens and the spacing scale (4, 8, 12, 16, 24, 32, 48, 64, 96, 128, 160).
- Respect reduced motion everywhere.
- Explain your reports in plain, simple language.

## Never
- Read, print, copy or commit `.env` values, keys or tokens.
- Log into or call production systems or client platforms.
- Take screenshots of client systems, or use project images other than `design-handoff/assets/work/`.
- Add claims, numbers, clients, testimonials or status labels that are not in the content file.
- Expose client system details: endpoints, tables, frameworks per project, security reviews, or links to confidential platforms.
- Call the youth programme an "academy", or show Foundation trustee photos.
- Publish or sell the Hyperspeed road code as a separate package (MIT + Commons Clause).
- Delete files outside the current phase's list without asking.
